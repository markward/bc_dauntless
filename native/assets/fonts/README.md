# Viewscreen bitmap font

`viewscreen_antonio.png` (greyscale coverage atlas, white on black) and `viewscreen_antonio.json` (glyph rects and metrics for ASCII 32-126) are GENERATED by `tools/fonts/gen_bitmap_font.py` from `native/assets/ui-cef/fonts/Antonio-Regular.ttf`; never hand-edit them. Regenerate with `uv run python tools/fonts/gen_bitmap_font.py` (add `--check` to test for drift; `PIXEL_SIZE` at the top of the tool is the size knob) and commit both files together. Antonio is licensed under the SIL Open Font License; see `native/assets/ui-cef/THIRD_PARTY/Antonio-OFL.txt`. The native viewscreen bars pass reads the atlas and JSON.
