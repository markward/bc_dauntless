#
# A failure listed here is treated as pre-existing and does NOT fail the gate.
# Any failure NOT listed here is a REGRESSION: tools/check_test_baseline.py exits
# non-zero and names it. This file is the single source of truth — never call a
# failure "pre-existing" by eyeball; if it's real and unavoidable, it goes here
# with a reason, otherwise it gets fixed. When a listed test starts passing, the
# gate tells you to delete its line (keep the ledger honest and shrinking).
#
# Format: one "<suite>:<test-id>" per line. <suite> is "pytest" or "ctest".
#   A ctest SKIP is baselined as "skip:ctest:<name>". With a BC content root
#   configured, any skip NOT listed fails the gate (a skip exits 0, so it was
#   otherwise invisible), and a listed skip that now runs asks to be deleted.
#   pytest id = the node id, e.g. pytest:tests/unit/test_foo.py::test_bar
#   ctest id  = the test name,  e.g. ctest:FrameTest.Baz
#   A ctest SKIP whose test only exercises an OPTIONAL MOD (present only on a
#   machine where that mod is installed) is baselined instead as
#   "optional-mod:ctest:<name> <path relative to the mods root>" -- e.g.
#   "optional-mod:ctest:Foo.Bar CGSovereign/data/x.nif". Unlike a plain
#   skip:, its legitimacy is judged by whether that path exists under the
#   resolved mods root (DAUNTLESS_MODS_DIR, else engine.mods.mods_root()):
#   path absent + skip = legitimate, not reported; path present + skip = a
#   NEW skip that fails the gate (something broke); ran at all = nothing
#   reported either way -- the line documents a dependency, not a fixed
#   expectation, so it is never asked to be deleted.
# Blank lines and lines starting with '#' are ignored.
