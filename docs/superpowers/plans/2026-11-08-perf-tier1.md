## Review Focus

1. **A contact that dies, cloaks or leaves the player's set mid-frame:** its row must go on the next frame, never wait for the sweep. Owned by Task 2 (`test_death_rebuilds_next_frame`, `test_set_removal_rebuilds_next_frame`, `test_cloak_completed_rebuilds_next_frame`).
2. **Opening the crew menu from the keyboard while the panel is throttled:** must draw on the next frame. Owned by Task 3 (`test_keyboard_show_menu_draws_next_frame`).
3. **A CEF resize that keeps w·h (a w/h swap) or a DPR change:** must take a full upload, never a stale dirty-rect copy. Owned by Task 4 (`DirtyRegion.SizeChangeForcesFull`, `CopyRects.SizeChangeCopiesWhole`).
4. **The F11 nonfinite probe turned on with R11G11B10F targets:** it must still find NaN, −Inf and its alpha cause codes. Owned by Task 5 (`HdrFormat.ProbeOnPicksRgba16f`).
5. **A GC freeze that outlives its mission:** after any teardown path, the old mission's objects must be collectable. Owned by Task 8 (`test_every_teardown_path_thaws`, `test_swapped_out_ship_is_collected`).

## Task 5: R11G11B10F scene and bloom targets — branch `perf/hdr-r11g11b10f`

**Audit result (from recon; recheck any line you touch):**
- **Only the nonfinite probe reads the scene target's alpha:** `nonfinite_probe.frag:64` reads `s.a`, and `opaque.frag:2207/2219` write it.
- **Blending never uses destination alpha.** No `glBlendEquation` exists, and the `GL_BLEND_DST_ALPHA` hits are state save/restore only.
- **Shaders that read RGB only:** `dof.frag` (computes CoC from depth and writes alpha 1), `resolve`, `bloom_*`, `motion_blur`, `lens_flare_*`, `filmic`, `nebula_godray*`, `cloak_refraction`.
- **The viewscreen feed:** `bridge.frag:596` alpha-tests `g_viewscreen_hdr` only for materials with an NiAlphaProperty. With R11F its alpha reads 1, so there are fewer discards, never more. Mark checks it.
- **The MSAA resolve:** `hdr_msaa_target.cc:70` blits into `g_hdr_target`, so the two must always share a format.
- **The nebula buffers** (`nebula_volumetric_pass.cc:69`, `system_nebula_pass.cc:184`) are separate RGBA16F targets that read alpha. They are untouched.
- **Bridge AO `pre_`** (`bridge_ao_pass.h:92`) keeps signed normals in an `HdrTarget`. That is why `HdrTarget`'s default stays RGBA16F.
- **The cloak copy** (`cloak_pass.cc:82`): float into float, RGB read. Fine.
- **Alpha-to-coverage** (`far_pass.cc:454`) uses the fragment's output alpha, not the stored one. Check impostor edges visually.
